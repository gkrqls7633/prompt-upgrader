# 예시: 모호한 요청 고도화 (upgrade, 질문형)

한 줄짜리 데이터 분석 요청을 넣으면, 원문을 채점하고 결과를 가장 크게 바꾸는 질문 3개를 먼저 한다.

## 입력

```text
지난달 매출 데이터 분석해줘
```

## 실행

```text
/prompt-upgrader upgrade "지난달 매출 데이터 분석해줘"
```

## 출력 (첫 응답)

prompt-upgrader v1.1.0 · 규칙 기준일 2026-11-21

## 원문 점수: 17/100 (재작성)
빠진 것: 분석 목적과 결과의 쓰임 (R-CTX-001 목적과 쓰임), 매출 데이터 원본 (누락: 입력 자료), 알고 싶은 질문과 볼 지표 범위 (누락: 분석 질문, 다룰 지표), 출력 형식 (R-OUT-001 출력 형식 명시), 읽을 사람 (R-CTX-003 독자 지정), 완료 기준 (R-CMP-001 완료 기준)

| 항목 | 점수 | 감점 근거 |
|---|---|---|
| U1 (목표와 행동) | 10/20 | "분석해줘": 동작은 있으나 무엇을 알아내려는 분석인지 없음 (누락: 분석 질문) |
| U2 (맥락과 이유) | 0/20 | 누락: 목적과 쓰임 (R-CTX-001) |
| U3 (입력 자료) | 0/15 | 누락: 매출 데이터 원본 또는 위치 |
| U4 (범위와 제약) | 7/15 | "지난달"로 기간은 있음. 누락: 다룰 지표, 비교 기준, 제외할 것 |
| U5 (출력 형식과 독자) | 0/15 | 누락: 출력 형식 (R-OUT-001), 독자 (R-CTX-003) |
| U6 (완료 기준) | 0/15 | 누락: 완료 조건 (R-CMP-001) |

## 확인하고 싶은 것
1. 이 분석 결과는 어디에 쓰이나요? (a) 경영진·상위 보고 (b) 매출 하락·상승 원인 파악 (c) 다음 달 예산·프로모션 같은 의사결정 (d) 정기 월간 리포트
2. 매출 데이터는 어떻게 주시나요? (a) 파일·표를 붙여 넣음 (b) 에이전트가 접근할 수 있는 DB·시트 위치를 알려줌. 함께 비교할 기준(전월, 전년 동월, 목표치)이 있으면 알려주세요.
3. 결과를 누가 어떤 형태로 보나요? (a) 임원용 결론 먼저 1페이지 요약 (b) 실무자용 지표 표와 세부 분석 (c) 슬라이드에 옮길 핵심 수치 몇 개

## 추천 프레임 (답을 받은 뒤 적용)
- **F-ANL-02 MECE**: 무엇을 봐야 할지 아직 정해지지 않은 탐색 단계라서, 매출을 "방문자 수 × 전환율 × 객단가"나 채널·상품별처럼 겹치지 않게 먼저 나누는 것이 맞다. 주의: 특정 지표 하나의 원인을 깊게 파야 하는 상황이면 맞지 않는다.
- **F-ANL-03 가설 기반 분석**: 1번 답이 (b)처럼 "왜 줄었나/늘었나"를 알려는 것이고 짐작 가는 원인이 있다면 가설부터 세워 검증하는 편이 빠르다. 주의: 가설을 세울 사전 지식이 없으면 F-ANL-02로 먼저 나눈다.

`바로`라고 답하면 지금 정보로 가정을 세워 진행합니다.

## 읽는 법

질문에 답하면 그 답을 반영한 개선본이 나온다. 질문에 답하기 번거로우면 '바로'라고만 답해도 된다. 그러면 가정을 세워 개선본을 만들고, 가정 목록을 함께 보여준다.
