# 예시: 모호한 요청 고도화 (upgrade, 질문형)

한 줄짜리 데이터 분석 요청을 넣으면, 원문을 채점하고 결과를 가장 크게 바꾸는 질문 3개를 먼저 한다.

## 입력

```text
지난달 매출 데이터 분석해줘
```

## 실행

```text
/prompt-upgrader upgrade "지난달 매출 데이터 분석해줘"
```

## 출력 (첫 응답)

prompt-upgrader v1.0.0 · 규칙 기준일 2026-11-21

## 원문 점수: 25/100 (재작성)
| 항목 | 점수 | 감점 근거 |
|---|---|---|
| U1 목표와 행동 | 14/20 | "분석해줘": 동작은 있으나 무엇을 밝히는 분석인지(추이, 원인, 비교) 없음 (R-CLR-004) |
| U2 맥락과 이유 | 0/20 | 누락: 분석 목적과 결과를 쓸 곳 (R-CTX-001) |
| U3 입력 자료 | 5/15 | "매출 데이터": 자료가 첨부되지 않았고 형태(파일, 표, 컬럼)도 불명 (R-STR-001, V-EVD-03) |
| U4 범위와 제약 | 6/15 | "지난달"로 기간만 있음. 누락: 대상(채널, 상품, 지역), 비교 기준(전월, 전년 동월), 제외할 것 (V-SCP-01, V-SCP-04) |
| U5 출력 형식과 독자 | 0/15 | 누락: 출력 형식 (R-OUT-001), 분량 (R-OUT-003), 독자 (R-CTX-003) |
| U6 완료 기준 | 0/15 | 누락: 어떤 결과가 나오면 끝인지 (R-CMP-001) |

빠진 것: 분석 목적 (R-CTX-001), 입력 자료 (R-STR-001), 범위와 비교 기준 (V-SCP-04), 출력 형식 (R-OUT-001), 분량 (R-OUT-003), 독자 (R-CTX-003), 완료 기준 (R-CMP-001)

## 확인하고 싶은 것
1. 이 분석 결과는 어디에 쓰이나요? (a) 경영진 월간 보고 (b) 매출 하락·상승 원인 파악 (c) 다음 달 예산·프로모션 결정 (d) 팀 내부 공유
2. 데이터는 어떤 형태로 줄 수 있나요? (a) CSV·엑셀 파일 첨부 (b) 표를 붙여넣기 (c) 아직 없음, 어떤 데이터가 필요한지부터 알고 싶음. 가능하면 주요 컬럼(날짜, 상품, 채널, 금액 등)도 알려주세요.
3. 결과는 누가 어떤 형태로 보나요? (a) 비전공 임원용 결론 먼저 1페이지 요약 (b) 실무자용 표와 지표 상세 (c) 슬라이드에 옮길 핵심 수치 3~5개

질문하지 않은 빈칸: 비교 기준(전월 대비, 전년 동월 대비)과 완료 기준은 답을 받은 뒤 목적에 맞춰 기본값을 제안합니다.

## 추천 프레임 (답을 받은 뒤 적용)
- **F-ANL-02 MECE**: 아직 특정 문제나 가설이 없는 탐색형 분석이라서, "매출 = 방문자 수 × 전환율 × 객단가"처럼 겹치지 않게 나눠 보는 것이 출발점으로 맞다. 주의: 특정 원인 하나를 깊게 파야 하는 상황이면 맞지 않는다.
- **F-ANL-03 가설 기반 분석**: 1번 답이 (b) 원인 파악이고 짐작 가는 원인이 있다면, 가설을 먼저 세워 검증할 데이터만 보는 편이 빠르다. 주의: 가설을 세울 사전 지식이 없으면 MECE로 먼저 나눈다.

`바로`라고 답하면 지금 정보로 가정을 세워 진행합니다.

## 재검증 필요
- 없음

## 읽는 법

질문에 답하면 그 답을 반영한 개선본이 나온다. 질문에 답하기 번거로우면 '바로'라고만 답해도 된다. 그러면 가정을 세워 개선본을 만들고, 가정 목록을 함께 보여준다.
