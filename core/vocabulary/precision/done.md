# 정밀 어휘: 완료와 검증 (DON)

언제 끝인지, 어떻게 확인할지를 정하는 어휘다.

## V-DON-01  다음이 모두 참이면 완료 / Done when
- 상황: 결과물이 갖춰야 할 조건이 분명할 때
- 약한 표현: "잘 만들어줘"
- 강한 표현: "다음이 모두 참이면 완료다: 1) 입력이 비어 있어도 오류가 나지 않는다 2) 기존 테스트가 모두 통과한다 3) 새 함수에 테스트가 있다."
- 효과가 있는 이유: 확인 가능한 조건이 있으면 모델이 스스로 결과를 점검한다
- 업무 예시: 문서 - "독자가 이 문서만 보고 신청까지 할 수 있으면 완료다."
- 관련 규칙: R-CMP-001
- verified: 2026-11-21 / claude-opus-5-5

## V-DON-02  이 방법으로 검증해 / Verify by
- 상황: 결과가 맞는지 실제로 확인해야 할 때
- 약한 표현: "확인해줘"
- 강한 표현: "고친 뒤 테스트를 실행하고, 실패한 테스트가 없을 때만 완료로 보고해."
- 효과가 있는 이유: 검증 방법을 지정하면 확인 없이 완료를 선언하는 일이 줄어든다
- 업무 예시: 데이터 - "집계 결과를 원본 리포트의 월 합계와 대조해서 확인해."
- 관련 규칙: R-CMP-002
- verified: 2026-11-21 / claude-opus-5-5

## V-DON-03  확인하지 못한 것을 적어 / State what was not verified
- 상황: 모든 것을 검증할 수 없는 환경일 때
- 약한 표현: (언급 없음)
- 강한 표현: "실행하지 못한 검사나 확인하지 못한 가정이 있으면 마지막에 목록으로 적어."
- 효과가 있는 이유: 검증된 것과 아닌 것이 구분되어 결과를 믿을 범위가 드러난다
- 업무 예시: 코딩 - "운영 환경에서만 재현되는 부분은 미검증으로 표시해."
- 관련 규칙: R-CMP-003
- verified: 2026-11-21 / claude-opus-5-5

## V-DON-04  끝까지 / See it through
- 상황: 여러 단계로 된 작업을 에이전트에게 맡길 때
- 약한 표현: "할 수 있는 만큼 해줘"
- 강한 표현: "요청한 항목이 모두 끝날 때까지 계속해. 확인이 필요한 작업에서만 멈추고 물어."
- 효과가 있는 이유: 중간에 멈추고 보고하는 조기 중단을 줄인다
- 업무 예시: 문서 - "목차의 모든 절을 다 채울 때까지 계속 써."
- 관련 규칙: R-CMP-004
- verified: 2026-11-21 / claude-opus-5-5

## V-DON-05  성공 지표 / Success metric
- 상황: 결과의 좋고 나쁨을 숫자로 판단할 수 있을 때
- 약한 표현: "효과적인 문구 만들어줘"
- 강한 표현: "목표는 클릭률이다. 각 문구가 클릭률을 높일 이유를 한 줄씩 붙여."
- 효과가 있는 이유: 무엇을 최적화하는지 알면 모델의 선택 기준이 하나로 정해진다
- 업무 예시: RAG - "목표는 상담원 연결 건수 감소다."
- 관련 규칙: R-CTX-001, R-CMP-001
- verified: 2026-11-21 / claude-opus-5-5
