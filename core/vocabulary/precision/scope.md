# 정밀 어휘: 범위 (SCP)

작업이 다룰 범위와 다루지 않을 범위를 정하는 어휘다.

## V-SCP-01  다음 범위만 / Only within
- 상황: 모델이 관련 없는 영역까지 손대는 것을 막고 싶을 때
- 약한 표현: "이 코드 정리해줘"
- 강한 표현: "src/payment 폴더 안의 파일만 수정해."
- 효과가 있는 이유: 범위를 명시하면 요청하지 않은 변경이 줄어든다
- 업무 예시: 코딩 - "이 PR에서 바뀐 파일만 리뷰해." / 데이터 - "2026년 3분기 데이터만 사용해."
- 관련 규칙: R-AGT-004, R-CLR-002
- verified: 2026-11-21 / claude-opus-5-5

## V-SCP-02  제외할 것 / Out of scope
- 상황: 흔히 따라붙는 작업을 이번에는 빼고 싶을 때
- 약한 표현: "필요한 것만 해줘"
- 강한 표현: "이번에는 디자인 수정과 성능 개선은 다루지 않는다. 문구만 고쳐."
- 효과가 있는 이유: 제외 목록이 있으면 모델이 기본으로 덧붙이는 작업을 하지 않는다
- 업무 예시: 문서 - "요약에서 배경 설명과 일정은 제외해."
- 관련 규칙: R-AGT-004
- verified: 2026-11-21 / claude-opus-5-5

## V-SCP-03  상위 N개 / Top N
- 상황: 결과가 너무 많아 우선순위가 필요할 때
- 약한 표현: "문제점들 알려줘"
- 강한 표현: "영향이 큰 순서로 상위 5개만 알려줘."
- 효과가 있는 이유: 개수와 정렬 기준을 주면 모델이 중요도를 판단해서 고른다
- 업무 예시: 데이터 - "이탈 원인 후보 상위 3개를 근거 지표와 함께." / 코딩 - "리뷰 지적 사항 상위 5개만."
- 관련 규칙: R-OUT-003
- verified: 2026-11-21 / claude-opus-5-5

## V-SCP-04  기간과 대상 한정 / Limit to
- 상황: 데이터나 분석 대상이 넓어 결론이 흐려질 때
- 약한 표현: "매출 분석해줘"
- 강한 표현: "2026년 10월, 온라인 채널, 신규 고객만 대상으로 매출을 분석해."
- 효과가 있는 이유: 대상이 좁아야 비교 기준과 결론이 분명해진다
- 업무 예시: RAG - "2026년 개정판 규정만 근거로 답해."
- 관련 규칙: R-CLR-002, R-CTX-001
- verified: 2026-11-21 / claude-opus-5-5

## V-SCP-05  다음을 가정해 / Assume that
- 상황: 모르는 조건 때문에 작업이 멈추지 않게 하고 싶을 때
- 약한 표현: (조건을 말하지 않음)
- 강한 표현: "예산은 월 500만 원, 개발자는 2명이라고 가정해. 가정이 결과를 크게 바꾸면 따로 적어."
- 효과가 있는 이유: 가정을 고정하면 모델이 임의 가정을 숨기지 않고, 결과의 전제가 드러난다
- 업무 예시: 문서 - "독자는 이 프로젝트를 처음 듣는다고 가정해."
- 관련 규칙: R-CTX-001
- verified: 2026-11-21 / claude-opus-5-5
