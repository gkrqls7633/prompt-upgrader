## E-05  5 Whys (F-ANL-01)
- A: 어제 배포 후 결제 API 응답이 30초씩 걸렸어. 로그를 보니 DB 커넥션 풀이 꽉 찼고, 새 기능에서 트랜잭션을 닫지 않는 코드가 있었어. 원인 정리해줘.
- B: 어제 배포 후 결제 API 응답이 30초씩 걸렸다. 로그상 DB 커넥션 풀이 꽉 찼고, 새 기능에 트랜잭션을 닫지 않는 코드가 있었다. 이 장애의 원인을 5 Whys로 분석해. 각 "왜"의 답마다 위 정보에서 근거를 붙이고, 근거가 없는 단계는 "추정"으로 표시해. 증상과 근본 원인을 구분해서 쓰고, 근본 원인에 대한 재발 방지책 3개로 끝내.
- 판정 기준:
  1. 원인 사슬이 3단계 이상 이어지는가
  2. 증상(응답 지연)과 근본 원인(예: 리뷰·테스트 공백)을 구분했는가
  3. 근본 원인에 대한 재발 방지책이 있는가
- 효과 있음: B가 A보다 판정 기준을 2개 이상 더 충족
