## C-23  3라운드 후에도 기준 미달 (선택지 제시)
- mode: upgrade
- input:
```text
보고서 써줘
```
- context: 이전 대화. 라운드 1: 스킬이 "어디에 쓰나요 / 누가 읽나요 / 어떤 형식인가요"를 물었고 사용자는 "주간 회의용, 팀장이 읽음"이라고 답했다. 라운드 2: 스킬이 "어떤 내용을 담나요 / 언제까지인가요 / 어떤 결과면 끝인가요"를 물었고 사용자는 "모르겠어요"라고 답했다. 라운드 3: 스킬이 "이번 주 한 일 중 넣을 것 / 분량 / 완료 조건"을 물었고 사용자는 "잘 모르겠어요, 그냥 알아서요"라고 답했다. 지금은 라운드 3의 답을 받은 직후다.
- must_flag: R-CMP-001
- must_not_flag: R-LEG-*
- expect: 개선본을 바로 내지 않음. 라운드 3/3 완료와 정보 충족도, 아직 빠진 것(완료 기준 등)을 보여줌. (a) 계속 답하기 (b) [확인 필요]로 둔 기준 미달 초안 받기 중 고르게 함. "모르겠다"고 한 항목을 다시 묻지 않음
