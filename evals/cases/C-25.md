## C-25  답이 부족하면 같은 항목을 다시 묻기
- mode: upgrade
- input:
```text
지난달 매출 데이터 분석해줘
```
- context: 이전 대화. 질문 목록(1. 알고 싶은 것 · 2. 쓰는 곳 · 3. 완료 기준)을 만들었다. 1번에는 "10월 매출이 왜 줄었는지 알고 싶다"고 답해 충분으로 확인됐다. 지금 2번 질문("이 분석 결과는 어디에 쓰이나요?")에 사용자가 "회의용"이라고만 답한 직후다.
- must_flag: R-CTX-001
- must_not_flag: R-LEG-*
- expect: 3번 질문으로 넘어가지 않음. 2번 답이 아직 부족한 이유(회의에서 무엇을 정하는지 등)를 한 줄로 말하고, 같은 항목을 범위를 좁혀 다시 물음. 예시 답이 있음. 개선본을 내지 않음. 질문은 하나만 있음
